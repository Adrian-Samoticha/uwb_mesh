A mesh network designed for UWB nodes.

`cargo run` launches a simulator that looks like this:

<img width="918" height="972" alt="image" src="https://github.com/user-attachments/assets/580d97a9-315b-41dd-ad87-9b4a7a9bf2c0" />

The code for the mesh is found in `src/device`. To run on actual hardware, the hardware interface found in `src/interfaces` needs to be implemented.
